# چک‌لیست سئو، GEO و AEO

کدِ سایت همهٔ کارهای فنی را انجام داده است. بخش‌های زیر کارهایی است که **فقط خود شما** می‌توانید انجام دهید. اینها تعیین می‌کنند سایت واقعاً در گوگل دیده شود.

> **یک نکتهٔ صادقانه:** هیچ‌کس، از جمله این کد، نمی‌تواند «لینک اول گوگل» را تضمین کند. عبارت‌هایی مثل «طراحی سایت» را شرکت‌های بزرگ با سال‌ها محتوا و بک‌لینک در اختیار دارند. سایت فنی‌اش آماده است؛ رتبه از محتوا، اعتبار و زمان می‌آید. راهبرد واقع‌بینانه در انتهای همین فایل است.

## ۱) پیش از انتشار
- [ ] `NEXT_PUBLIC_SITE_URL` را روی دامنهٔ نهایی (https، بدون اسلش پایانی) تنظیم کنید و بیلد بگیرید. سایت باید روی ریشهٔ دامنه باشد.
- [ ] رزومه‌های `public/resume.pdf` و `resume-fa.pdf` را با اطلاعات سایت یکی کنید (شهر، سطح Next.js/TypeScript) و تصمیم بگیرید «حقوق مورد انتظار» داخل فایل عمومی بماند یا نه.
- [ ] عکس شفاف خودتان را در `public/images/portrait.webp` بگذارید.
- [ ] متن‌ها، درصد مهارت‌ها و ادعاها را بخوانید و مطمئن شوید همه دقیقاً دربارهٔ شماست (Next.js و TypeScript را «در حال یادگیری» نوشته‌ام؛ هر طور واقعی است اصلاح کنید).
- [ ] `npm run build && npm run audit:seo` بدون خطا باشد.

## ۲) بعد از انتشار (روز اول)
1. **Google Search Console** → افزودن Property از نوع *Domain* (تأیید با DNS) یا *URL prefix* (متای تأیید: مقدارش را در `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` بگذارید و دوباره بیلد کنید).
2. Sitemaps → ارسال `https://دامنه/sitemap.xml`.
3. URL Inspection → برای `/`، `/en/` و چهار صفحهٔ خدمات «Request indexing» بزنید.
4. [Bing Webmaster Tools](https://www.bing.com/webmasters) → وارد کردن از Search Console (چند ثانیه). Bing منبع بسیاری از دستیارهای هوش مصنوعی است.
5. یک دامنهٔ واحد: http→https و www→non-www (یا برعکس) با ریدایرکت ۳۰۱ (نمونهٔ کامنت‌شده در `public/.htaccess`).
6. در [PageSpeed Insights](https://pagespeed.web.dev) و [Rich Results Test](https://search.google.com/test/rich-results) آدرس صفحه‌ها را تست کنید.

## ۳) اعتبار بیرونی (مهم‌ترین عامل رتبه)
- آدرس سایت را در پروفایل **GitHub** (فیلد Website)، **LinkedIn** (Contact info و Featured)، و هر جایی که پروفایل دارید بگذارید. پروفایل‌ها در `sameAs` داده‌ساختاریافته هم هستند، پس ارتباط دوطرفه شکل می‌گیرد.
- در README مخزن‌های GitHub (مثل نمونه‌کدها) لینک به سایت بدهید.
- مقاله بنویسید و در Virgool/Medium/dev.to منتشر کنید و به صفحات خدمات لینک بدهید.
- از همکاران و کارفرمایان قبلی بخواهید در سایت یا پروفایل خودشان به شما لینک بدهند (لینک‌های واقعی؛ خرید لینک ریسک جریمه دارد).
- اگر نشانی کسب‌وکار دارید، **Google Business Profile** بسازید.

## ۴) محتوا (دومین عامل مهم)
هر عبارتی که می‌خواهید در آن دیده شوید، باید صفحه‌ای مخصوص خودش داشته باشد. الان چهار صفحه هست (طراحی سایت، برنامه‌نویسی وب، React/Next.js، سئو فنی). پیشنهاد صفحات و مقالات بعدی:
- «برنامه‌نویس React در تهران»، «طراحی سایت شرکتی با Next.js»، «تفاوت React و Next.js»
- «هزینهٔ طراحی سایت چقدر است؟ (راهنمای عوامل مؤثر)»، «چک‌لیست سئو فنی برای سایت‌های React»
- مطالعهٔ موردی از پروژه‌هایی که اجازهٔ انتشارشان را دارید (بدون افشای اطلاعات محرمانهٔ سازمان‌ها).

برای افزودن صفحهٔ خدمات جدید:
1. slug را به `serviceSlugs` در `src/lib/site.ts` اضافه کنید.
2. متن صفحه را در `src/data/services-fa.ts` و `services-en.ts` بنویسید.
3. کارت آن را به `services.items` در `src/data/fa.ts` و `en.ts` اضافه کنید (برای لینک از صفحهٔ اصلی).
4. تصویر اشتراک‌گذاری را در `scripts/generate-assets.mjs` (شیء `cards`) تعریف کنید و `npm run assets` را اجرا کنید.
5. `npm run build && npm run audit:seo`؛ sitemap، hreflang و JSON-LD خودکار ساخته می‌شوند و ممیزی هر کمبودی را نشان می‌دهد.

## ۵) آنچه کد برایتان انجام داده است
**سئو فنی:** HTML معنایی با یک `<h1>`، title/description یکتا برای هر صفحه، canonical، hreflang (fa / en / x-default)، sitemap با alternates، robots.txt، Open Graph و Twitter Card با تصویر اختصاصی، favicon و آیکون‌ها، فونت‌های خودمیزبان (بدون Google Fonts که در ایران کند است)، بارگذاری سریع (Server Components و حداقل جاوااسکریپت)، صفحهٔ ۴۰۴ سفارشی، سایت بدون JS هم خوانا است.

**داده‌ساختاریافته (JSON-LD):** `WebSite`، `Person` (با sameAs، knowsAbout، محل، سابقه)، `ProfilePage`، `Service` برای هر خدمت، `FAQPage`، `BreadcrumbList`. توجه: طبق اعلام گوگل (از ۲۰۲۳) نتیجهٔ غنی FAQ فقط برای سایت‌های دولتی/سلامت نشان داده می‌شود؛ این مارکاپ همچنان به درک محتوا کمک می‌کند ولی انتظار «اسنیپت FAQ» در نتایج نداشته باشید.

**AEO (پاسخ مستقیم):** پرسش‌ها و پاسخ‌های کوتاه و مستقل (جمله‌ٔ اول پاسخ، جواب است) در صفحهٔ اصلی و هر صفحهٔ خدمات.

**GEO (موتورهای هوش مصنوعی):** `/llms.txt` و `/llms-full.txt` (خلاصهٔ ساختارمند و متن کامل، فارسی و انگلیسی)، robots.txt که خزنده‌های GPTBot، ClaudeBot، PerplexityBot، Google-Extended و … را صراحتاً مجاز می‌کند، «کارت مشخصات» با حقایق قابل‌نقل (نام، نقش، شهر، تجربه، مهارت‌ها)، و هویت واحد (Person) که به GitHub و LinkedIn وصل است.

## ۶) راهبرد واقع‌بینانه برای رتبه
1. ابتدا عبارت‌های **دقیق‌تر و کم‌رقابت‌تر** را هدف بگیرید: «برنامه‌نویس React تهران»، «طراحی سایت با Next.js»، «سئو فنی سایت React»، «برنامه‌نویس فرانت‌اند». اینها در ۳ تا ۶ ماه قابل‌دسترس‌ترند.
2. با رشد اعتبار (لینک‌ها و مقالات) به سراغ «برنامه‌نویس وب» و بعد «طراحی سایت» بروید.
3. هر ماه Search Console → Performance را ببینید: کدام عبارت‌ها نمایش دارند اما کلیک ندارند؟ title/description همان صفحه را بهتر کنید.
4. تغییر مهم محتوا = بروزرسانی `CONTENT_UPDATED` و درخواست ایندکس مجدد.
